# A-Real-time-Framework-of-Collaborative-State-Estimation-with-Collision-Free-Control

This paper proposes a real-time framework for collaborative state estimation and collision avoidance during satellite cluster reconfiguration under limited observational resources. Due to resource heterogeneity, the cluster adopts a multi-leader–multi-follower collaborative architecture with a directed communication topology, instead of a fully distributed architecture with bidirectional information sharing. An event-triggered mechanism (ETM) is introduced to reduce communication, enabling members to correct state estimates and share obstacle information. A matrix-norm-based fusion algorithm ensures accurate state estimation for all satellites. For collision avoidance, a dynamic artificial potential field (DAPF) controller is designed for efficient collision avoidance, with an adaptive repulsive field that stretches to provide early warnings. Theoretical analysis proves an upper bound for both inter-event communication intervals and estimation errors. Numerical simulations confirm that the framework ensures effective obstacle avoidance and drives state estimates to converge near true values, with the ETM balancing estimation performance and communication efficiency.The semi-physical platform experiments further demonstrate the real-time performance of the proposed framework.
